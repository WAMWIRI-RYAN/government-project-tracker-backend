# Government Project Tracker Backend

## Requirements

- Node.js 18+
- PostgreSQL
- Firebase Project

## Installation

Install dependencies:

```bash
npm install
```

Create a `.env` file using `.env.example`.

Start the server:

```bash
npm start
```

Server runs on:

```
http://localhost:3000
```

## Main Features

- Firebase Authentication
- Users
- Projects
- Audits
- Evidence Upload
- Community Comments
- Watchlist
- Notifications
- Locations

## API Base URL

```
http://localhost:3000/api
```
